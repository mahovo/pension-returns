Pension returns

Martin Hoshi Vognsen

Return analyses of the pension plans at Velliv and PFA, and tools for deciding what to do with the savings. The history is short and the tails are fat. Each analysis therefore says how far its conclusions can be trusted.

Decision tools

Which plan to save in, and how to take the money out.

Choosing a pension plan: An investor’s advanced decision tool

Which risk level, and one provider or both? The tool answers both questions from the latest monthly returns and each provider’s fees. It shows how robust each answer is rather than naming a single best plan.

Kapital eller rate

Hvad er en kapitalpension værd, hvis den laves om til ratepension? Beregneren regner skat og folkepension år for år, med og uden raten. Resultatet sammenlignes med de 60 %, kapitalpensionen giver efter afgift. Satser for 2026.

Analysis

What thirteen years of annual returns can and cannot tell you.

Annual pension returns analysis

A case study on a frozen data set of annual returns from 2011 to 2023. It shows how far inference degrades when only annual data is available. The sample is far too short to estimate the tail, and it contains no crash.

Notes

Working notes on the fat-tailed statistics behind the analyses.

Notes on Taleb’s kappa

How many Student t summands does it take to match the convergence of n Gaussian ones? Works through Taleb’s convergence metric κ from The Statistical Consequences of Fat Tails, computed by simulation for the skewed t.

EnglishPDF7 pages

A study of the skewed generalized t-distribution

How the four parameters of a skewed t change when returns are summed over many periods. Estimated by simulation, with the analytical moments and a comparison of estimation packages.

EnglishPDF29 pages

Importance sampling of return paths

Working notes on importance sampling for simulated return paths. A skewed t target, a normal proposal tuned for minimum variance, and the open problem of the skewed t’s self-convolution.

EnglishPDF15 pages
